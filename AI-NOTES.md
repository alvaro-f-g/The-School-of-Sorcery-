# AI-NOTES.md

## AI Collaboration & Usage Experience

As part of the development process for the "School of Sorcery" project, AI was utilized strictly as a technical assistant and collaborative copilot to streamline syntax, organize documentation, and accelerate implementation. All core architectural decisions, code integration, environment troubleshooting, and final validations were driven independently.

### How AI Was Consulted
- **Boilerplate & Syntax Guidance**: Assisted in drafting initial Java structures and GSON parsing configurations, which were then adapted to fit local project requirements.
- **Sorting Logic Discussion**: Acted as a sounding board for structuring custom Java comparators to fulfill deterministic sorting constraints.
- **Documentation Drafts**: Helped structure and format the `README.md` instructions and initial markdown drafts, ensuring clear guidance for repository cloning and execution.

### Reflections
Using AI as a supplementary tool streamlined repetitive documentation and boilerplate tasks, allowing focus to remain on overall system design, execution testing in Visual Studio Code, and ensuring the application met its functional goals.
